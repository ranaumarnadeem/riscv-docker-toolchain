# Support

Thank you for using the RISC-V Toolchain extension for VS Code.

## Getting Help

### Documentation
Please refer to the extension README for usage instructions and troubleshooting tips.

### Issue Tracker
If you encounter a bug or have a feature request, please open an issue on our GitHub repository:

https://github.com/ranaumarnadeem/riscv-docker-toolchain/issues

When reporting an issue, please include:
- VS Code version
- Extension version
- Operating system
- Docker version
- Steps to reproduce the issue
- Any error messages from the Output panel

### Discussions
For general questions and discussions, use the GitHub Discussions feature:

https://github.com/ranaumarnadeem/riscv-docker-toolchain/discussions

## Response Time

This is an open-source project maintained on a voluntary basis. While we strive to respond to issues promptly, response times may vary.

## Contributing

Contributions are welcome. Please see the repository for contribution guidelines.
